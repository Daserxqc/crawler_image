## 踩过的坑

### 1. API 端口 / 进程
- **现象**：`run_api.py` 报 10048（端口占用）；Ctrl+C 后仍占 8000。
- **原因**：对话里后台另起过一份 uvicorn，终端 Ctrl+C 杀不到。
- **处理**：按 PID / 端口杀进程；同时只保留一份服务。

### 2. `/api/posts/search` → Not Found
- **现象**：岗位检索失败，前端显示 `Not Found`。
- **原因**：旧进程未加载新路由。
- **处理**：改完后端必须重启 API；前端硬刷新。

### 3. 「去许绍华」当人名
- **现象**：现任里出现「去许绍华」。
- **原因**：辽阳等写法是「免去姓名+全称岗位+职务」，免职正则没覆盖；花名册兜底把「去+姓名」当成 4 字人名，且记成 appoint。
- **处理**：补 glued 免职句式；人名禁 `去` 开头；重解析脏公告。

### 4. 同一岗位两人「都现任」
- **现象**：王红岩、连向军同为运城第一稽查局局长现任。
- **原因**：任期只按「同人再次变动 / 免职」关闭，新人上任不关前任。
- **注意**：卸任日多为**推定**（公开检索未必有「免去王红岩」）；局长一岗一人可推，但不是铁证。不要把「2025-08-07」看成「2023-08-07」（否则会误以为任期十几天）。

### 5. 职务下拉有、岗位搜不到
- **现象**：选「副所长（区县）」→ 0 条。
- **原因**：下拉展示的是目录标签 `副所长（区县）`，`org_posts.title` 存的是公告原文 `副所长`。
- **处理**：查询前剥掉（总局/省级/市局/区县）后缀，并按标签收窄层级。

### 6. 岗位列表信息层级反了
- **现象**：扫各地同一岗时，重复的「第一稽查局·副局长」加粗，地区反而是灰小字。
- **处理**：已选科室+职务时，主标题用地区；「查看档案」保持原按钮样式，别改成过小的文字链。

### 7. 列表塞现任/历任姓名
- **现象**：有「查看档案」还在行内写姓名，且常与现任名单重复。
- **处理**：列表只保留人数；详情进 `/posts/view`。

### 8. 工程/环境杂项
- PowerShell 下别直接改中文 HTML（易乱码）→ 用 `tools/gen_account_html.py`。
- http/https 同源公告会双条入库，重建岗位时要按「人+动作+岗+日」去重，否则会出现起止日相同的假历任。
- `org_posts` 全量重建较慢（约数分钟），改任期逻辑后需跑 `rebuild_org_posts.py`。
